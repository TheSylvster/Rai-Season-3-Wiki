# Rai Season 3 Wiki

The wiki for Season 3 of the Rai Minecraft server, covering custom crops and cooking, steel and muskets, new ores, and alchemy.

**Visit it:** https://thesylvster.github.io/Rai-Season-3-Wiki/

- Crafting information comes from JR's Crafting Guide for Season 3.
- The site is built by TheSylvster and hosted by ZapadTelecom©.

All pages are written in `assets/content.js`. See `CLAUDE.md` for how the site works and how to add pages.
